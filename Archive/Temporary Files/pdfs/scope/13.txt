Implementing the Rational Constructor
Rational.cpp: include "Rational.h" first. A constructor hasno return type.
Rational::Rational(int n, int d)
: num(n), den(d) {
if (den == 0) {
throw std::invalid_argument("zero denominator");
}
int g = gcd(std::abs(num), std::abs(den));
num /= g;
den /= g;
if (den < 0) {
num = -num;
den = -den;
}
}
gcd is a supplied helper. Check the denominator, reduce, then fix the sign.
Trace: (6,−8)→(3,−4)→(−3,4) ( 0,5)→(0,1).

Tokens and the Scanning Loop
A token is one piece of text; it can contain several characters.
Here, TokenScanner comes from theStanford C++ Library(tokenscanner.h).
TokenScanner scanner;
scanner.ignoreWhitespace();
scanner.setInput("ab + 12");
while (scanner.hasMoreTokens()) {
std::string token = scanner.nextToken();
std::cout << "[" << token << "] ";
}
[ab] [+] [12]
7 characters, 3 tokens:consecutive letters or digits stay together.
Why use it?Split expressions or commands into useful pieces.
The object remembers progress; scanning doesnot evaluatethe expression.
